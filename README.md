# Salcedo_Ysh_FA3_P1

## Description

This program computes the number of points to add to a canteen meal card, checks that the entry is valid, computes the bonus earned, and prints out the points added, the bonus given, and the new total.

## How to Run

1. Open the program file in VS Code, Replit, or Google Colab.

2. Run the program.

3. Enter "How many points?"

4. Check the number of your points, your added points, the bonus points given, and your new total displayed on the screen.

## Input Needed

-Total number of points to add to a canteen meal card

## Sample Output 1

How many points? 123 

Points added: 123

Bonus given: 10

New total:  133
